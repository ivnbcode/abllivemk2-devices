# Catálogo de Dispositivos Max for Live (`max-for-live/`)

Esta carpeta agrupa todos los dispositivos **Max for Live (`.amxd`)** para **Ableton Live**, cada uno dentro de su propia subcarpeta con sus scripts de soporte (`.js`, `.maxpat`), paquete `.zip` y compilador.

---

## Dispositivos Disponibles

| # | Dispositivo | Carpeta | Tipo | Descripción |
| :- | :--- | :--- | :--- | :--- |
| **01** | **OMNI-LAB MkII** | [`omnilab-mk2/`](./omnilab-mk2/) | MIDI Effect | Emulador de Strumplate (Sonic Strings de 16 cuerdas) y matriz de acordes del Suzuki Omnichord controlado con la tira táctil de Modulación (`CC 1`), Pads (`36-43`) y teclas del **Arturia MiniLab MkII**. |
| **02** | **SPATIAL-LAB 3D MkII** | [`spatiallab-3d/`](./spatiallab-3d/) | Audio Effect | Posicionador de Audio Espacial Binaural 3D (HRTF ITD/ILD + Elevación + Distancia + Órbitas LFO + Sala 3D) controlado con Knobs, Tira Mod (`CC 1` giro 360°) y Pads (`36-43`) del **Arturia MiniLab MkII**. |
